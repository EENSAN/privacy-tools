OTPauth Privacy Policy

Last updated: September 14, 2026

OTPauth is a password and two-factor authentication manager designed to securely save, retrieve, and fill login credentials and one-time authentication information.

This Privacy Policy explains what information OTPauth handles, why it is needed, how it is protected, and how it may be transmitted.

1. Information OTPauth Handles

OTPauth may handle the following categories of information solely to provide its password-management and two-factor authentication functionality.

1.1 Personally Identifiable Information

OTPauth may process usernames, account names, and email addresses that users save as part of their login credentials.

1.2 Authentication Information

OTPauth may process authentication data including:

  • Usernames
  • Passwords
  • Login credentials
  • Two-factor authentication secrets and codes
  • Other authentication-related information explicitly saved by the user

This information is necessary to provide password storage, autofill, login capture, and two-factor authentication functionality.

1.3 Website Information

OTPauth may process the hostname, domain, origin, or URL associated with a saved login so that credentials can be matched with the correct website.

OTPauth does not build a general browsing-history profile or track websites for advertising, analytics, or behavioral profiling purposes.

1.4 Extension Settings

The browser extension may store local settings required for its operation, including lock state, configuration, and other functional preferences.

2. How Information Is Used

OTPauth uses user data only to provide and maintain its primary password-management and two-factor authentication functionality. This includes:

  • Saving login credentials requested by the user
  • Matching saved credentials to websites
  • Filling login forms
  • Providing two-factor authentication codes
  • Locking the local vault after inactivity
  • Communicating securely with the locally installed OTPauth application
  • Synchronizing encrypted vault information when synchronization is enabled
  • Maintaining the security and reliability of OTPauth

OTPauth does not use user data for advertising, profiling, marketing, credit scoring, or purposes unrelated to OTPauth's password-management functionality.

3. Local Processing

OTPauth is designed as a local-first application.

The browser extension communicates with the OTPauth application installed on the same computer using Chrome Native Messaging.

Sensitive vault operations are handled by the local OTPauth application rather than being performed by the browser extension alone.

Communication between the browser extension and the native OTPauth application on the same computer is used only to provide OTPauth functionality.

4. Synchronization

If synchronization is enabled, OTPauth may transmit encrypted vault data to the OTPauth server configured for the user's account.

Sensitive vault information is encrypted before synchronization.

The synchronization service is not intended to receive passwords, two-factor authentication secrets, or other vault contents in readable plaintext form.

Synchronization is used only to allow the user to access their encrypted OTPauth data across authorized installations or devices.

5. Data Sharing

OTPauth does not sell user data.

OTPauth does not transfer user data to advertising networks, data brokers, or information resellers.

OTPauth does not use or transfer user data for personalized advertising, retargeting, interest-based advertising, lending, or creditworthiness decisions.

User data may only be disclosed where it is:

  • Necessary to provide functionality explicitly requested by the user;
  • Required by applicable law; or
  • Necessary to investigate or protect against security threats, fraud, malware, or abuse.

6. Human Access to User Data

OTPauth is designed so that sensitive vault information is not made available for routine human inspection.

OTPauth does not allow developers, employees, or other persons to read users' passwords, two-factor authentication secrets, or vault contents as part of normal operation.

User information would only be accessed where the user explicitly provides specific information for support, where required by law, or where necessary for a legitimate security investigation.

7. Security

OTPauth treats authentication information as sensitive data.

Reasonable technical safeguards are used to protect OTPauth data, including encryption of sensitive vault information and secure handling of authentication data.

Sensitive user data transmitted over a network must be protected using modern cryptography.

OTPauth requests browser permissions only where they are necessary to provide its stated password-management and authentication functionality.

Google requires extensions handling personal or sensitive information to handle it securely and to use modern cryptography for network transmission.

8. Browser Permissions

OTPauth uses browser permissions only for functionality directly related to its single purpose. These may include:

PermissionPurpose
Host permissionsUsed to detect login forms, associate credentials with websites, fill saved credentials, and offer to save login information.
storageUsed for extension settings, lock state, and other local operational preferences.
idleUsed to detect inactivity so OTPauth can automatically lock access to the local vault for security.
nativeMessagingUsed to communicate with the locally installed OTPauth application on the same computer.

OTPauth does not use these permissions to monitor users for advertising or unrelated analytics.

9. Remote Code

The OTPauth browser extension does not execute remotely hosted JavaScript or WebAssembly code.

Executable extension code is included in the extension package distributed through the Chrome Web Store.

Data received from a server is treated as data and is not downloaded and executed as extension code.

10. Data Retention and Deletion

Locally stored OTPauth data remains on the user's computer until it is deleted by the user or the local OTPauth data is removed.

Removing the browser extension does not necessarily delete data owned by the separately installed OTPauth desktop application.

If synchronization is enabled, encrypted synchronized information may remain on the configured synchronization service until it is deleted according to the OTPauth account or server's available deletion process.

Users may contact the developer regarding deletion or privacy questions using the contact information below.

11. Third-Party Advertising and Analytics

OTPauth does not use user authentication data for advertising.

OTPauth does not sell or provide authentication information to advertising networks, data brokers, or analytics providers for behavioral profiling.

12. Chrome Web Store Limited Use Compliance

OTPauth's use of user data is limited to providing and improving its disclosed password-management and two-factor authentication functionality.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

OTPauth does not use or transfer user data for purposes unrelated to the extension's single purpose.

Google's Limited Use policy specifically requires use of personal or sensitive data to stay tied to the extension's disclosed single purpose and prohibits transferring it for personalized advertising, data brokerage, or creditworthiness decisions.

13. Children's Privacy

OTPauth is not specifically designed or directed toward children under the age of 13.

14. Changes to This Privacy Policy

This Privacy Policy may be updated when OTPauth's functionality or data-handling practices change.

Any material change to how OTPauth handles user data will be reflected in an updated version of this policy and, where required, in the Chrome Web Store disclosures.
